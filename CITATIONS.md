# LoReRNA: Citations

If you use LoReRNA for your analysis, please cite the tools below.

> **Note on completeness.** Entries marked *(repository)* are tools for which a
> formal citation was not verified when this file was written — please check the
> project's own README for the citation it asks for before publishing.

## Pipeline framework

- **Nextflow**
  Di Tommaso P, Chatzou M, Floden EW, Barja PP, Palumbo E, Notredame C.
  Nextflow enables reproducible computational workflows.
  *Nature Biotechnology* 2017;35(4):316–319. doi:[10.1038/nbt.3820](https://doi.org/10.1038/nbt.3820)

## Alignment correction and BAM handling

- **MisER** — micro-exon rescue and splice-junction correction *(repository)*
  <https://github.com/zhqu1148980644/MisER>

- **SAMtools**
  Danecek P, Bonfield JK, Liddle J, et al. Twelve years of SAMtools and BCFtools.
  *GigaScience* 2021;10(2):giab008. doi:[10.1093/gigascience/giab008](https://doi.org/10.1093/gigascience/giab008)

## Transcript discovery and reference preparation

- **IsoQuant**
  Prjibelski AD, Mikheenko A, Joglekar A, et al. Accurate isoform discovery with
  IsoQuant using long reads.
  *Nature Biotechnology* 2023;41:915–918. doi:[10.1038/s41587-022-01565-y](https://doi.org/10.1038/s41587-022-01565-y)

- **GffCompare / GffRead**
  Pertea G, Pertea M. GFF Utilities: GffRead and GffCompare.
  *F1000Research* 2020;9:304. doi:[10.12688/f1000research.23297.2](https://doi.org/10.12688/f1000research.23297.2)

## Transcript quantification

- **oarfish** — long-read transcript quantification with coverage modelling *(repository)*
  <https://github.com/COMBINE-lab/oarfish>

## Differential analysis

- **Swish / fishpond**
  Zhu A, Srivastava A, Ibrahim JG, Patro R, Love MI. Nonparametric expression
  analysis using inferential replicate counts.
  *Nucleic Acids Research* 2019;47(18):e105. doi:[10.1093/nar/gkz622](https://doi.org/10.1093/nar/gkz622)

- **SummarizedExperiment** — Bioconductor container class used for the
  transcript-level objects passed to swish.
  <https://bioconductor.org/packages/SummarizedExperiment/>

## Reporting and visualisation

- **MultiQC**
  Ewels P, Magnusson M, Lundin S, Käller M. MultiQC: summarize analysis results
  for multiple tools and samples in a single report.
  *Bioinformatics* 2016;32(19):3047–3048. doi:[10.1093/bioinformatics/btw354](https://doi.org/10.1093/bioinformatics/btw354)

- **R** — R Core Team. *R: A Language and Environment for Statistical Computing*.
  R Foundation for Statistical Computing. <https://www.R-project.org/>

- R packages used for figures: **ggplot2**, **ggrepel**, **pheatmap**,
  **patchwork**, **scales**, **viridis**, **RColorBrewer**, **data.table**,
  **arrow**.
